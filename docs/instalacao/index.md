# Instalação

Esta secção é para quem vai instalar um servidor ForensicVM. A ordem recomendada é:

1. {doc}`pre-requisitos`: hardware e onde instalar;
2. {doc}`ubuntu-server`: o sistema operativo base;
3. {doc}`forensicvm`: um único comando instala a plataforma;
4. {doc}`https-intranet`: HTTPS e autenticação forte numa rede isolada (recomendado);
5. {doc}`cape`: o módulo opcional de análise de malware.

Depois da instalação, a gestão do dia a dia (serviços, atualização, cópias de segurança, resolução de
problemas) está em {doc}`../administracao/index`.

