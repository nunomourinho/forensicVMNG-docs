# Administração do sistema

Esta secção é para quem gere o servidor ForensicVM: os serviços, como se param e arrancam, onde estão os
registos, como se atualiza, como se fazem e repõem cópias de segurança e como se resolvem os problemas
mais comuns.

Os comandos correm como root na pasta de instalação do ForensicVM (a do `git clone`, onde está o
`install.sh`):

```bash
sudo -i
cd <pasta-do-forensicvm>
```
