# Session recording

Everything the investigator does on the machine can be recorded on video. It is the practical way to
document forensic work, and it is done in the console itself, with the acquisition button.

```{video} 08-gravacao-da-sessao
```

## The acquisition panel

In the console, the **acquisition** button (the first in the bottom toolbar) opens the panel with:

- **Screenshots:** capture, and download them all (ZIP);
- **Screen Recording:** start or stop, and the list of recordings;
- **Evidence:** download the evidence disk and capture a memory dump.

```{figure} /_static/img/08-gravacao-da-sessao/02a.jpg
:alt: Acquisition panel in the console with screenshots, recording and evidence

The acquisition panel.
```

## Recording

1. Press **Start Recording**. The server starts recording the machine's screen, and a red indicator
   shows that the recording is in progress.
2. Work on the machine as usual.
3. At the end, press **Stop Recording**. The file is stored on the server.

The recording is made on the server, from the virtual machine's screen. It does not depend on the
investigator's computer.

## Playing back and downloading

The recording appears in the panel's list, with the date and time. It can be played back right there, or
downloaded to be added to the case file.

```{figure} /_static/img/08-gravacao-da-sessao/04a.jpg
:alt: Playing back a recording in the browser, with the download button

Playing back a recording.
```

## Screenshots

You can capture the screen at any time. **Download all** puts all the screenshots into a single ZIP
file.

```{figure} /_static/img/08-gravacao-da-sessao/05a.jpg
:alt: Acquisition panel with the option to download all screenshots

Screenshots on demand.
```

```{tip}
Record the critical steps of the examination, such as getting into the account, running a plug-in or
collecting an artefact. Video and screenshots provide a visual record of the examination, ready to be
added to the forensic report.
```
