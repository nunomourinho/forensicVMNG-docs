# System administration

This section is for whoever manages the ForensicVM server: the services, how to stop and start them,
where the logs are, how to update, how to make and restore backups and how to solve the most common
problems.

The commands run as root in the ForensicVM installation folder (the one from `git clone`, where
`install.sh` is):

```bash
sudo -i
cd <forensicvm-folder>
```
