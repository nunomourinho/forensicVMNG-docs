# Installation

This section is for whoever is going to install a ForensicVM server. The recommended order is:

1. {doc}`prerequisites`: hardware and where to install;
2. {doc}`ubuntu-server`: the base operating system;
3. {doc}`forensicvm`: a single command installs the platform;
4. {doc}`https-intranet`: HTTPS and strong authentication on an isolated network (recommended);
5. {doc}`cape`: the optional malware analysis module.

After installation, day-to-day management (services, updates, backups, troubleshooting) is covered in
{doc}`../administration/index`.
